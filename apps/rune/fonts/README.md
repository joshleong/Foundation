# Hanken Grotesk, for Rune

Unpacked from `@fontsource-variable/hanken-grotesk` 5.3.0 by `scripts/rune-fonts.py` (WOFF2 to TrueType;
the Latin Extended files are renamed *Hanken Grotesk Ext*). SIL Open Font License 1.1, as the package's.
`npm run rune:build` copies them beside the wasm, where Rune fetches them.
