Foundation 0.2.0 is the first release that runs as a desktop app on Windows, and the first where the agents working on a board are people-shaped: you can see them, follow them and stop them.

## The crew

Hold **Space** and say what you want. An agent joins the board with a name and a cursor, says what it plans, and does the work in front of you. Its cursor lands on each card it touches. When it's done it brings your view to what it made.

- **Agents point.** While an agent explains something, it can point at a table cell or a port. A small laser marks the spot, and the cell lights up.
- **Follow an agent.** Press Follow and your view rides along with its cursor until you move.
- **Stop all.** One press stops every agent of yours on the board, helpers included. It's in the crew roster and in ⌘K.
- **Agents sign their work.** A note or table made by an agent says which one made it ("✦ Swift"), and the activity log knows it too.
- **Asks you finished stay findable** for 15 minutes in the voice sheet.

## Sections

- **Sections fit instead of scrolling.** A section's content scales to fit the section. **Expand** opens one section as its own grid, at full size, over its neighbours.
- **The + buttons in the gaps between sections ignore double-clicks**, so a quick double-click on paper doesn't add a section by accident.
- **A card a person adds to an app's section** sits beside the app instead of under it.
- **Framing a section keeps its tools in view.**

## The board

- **The daily digest.** Once a day a note on the company board says what changed: sections, cards, agents' runs.
- **Machines in a section.** Start a container (Kiri or Docker) in a section; its ports become pages on the board that follow the machine.
- **Writing together in notes**, with everyone's cursor, and a press no longer re-renders the whole board.
- **Huddle recordings know their length** (the WebM duration is written in), and huddle state lives in its own map, so two people's changes no longer race.

## On Windows

- **A desktop app and installers** (`Foundation_0.2.0_x64-setup.exe`, `.msi`). It shows a board from a Foundation server on this computer, signs in and syncs live. Boards you've opened before still open when the server is down.
- **Keys say Ctrl on Windows and Linux**, ⌘ on a Mac.
- **The agent starts Claude Code without a shell**, Vision Code is found on Windows and Linux, and REA jobs start too.
- **Launchers take their children with them**: a hard-killed `npm run dev` no longer leaves servers behind.

## The plan, in the open

Foundation's own plan is a kanban in **Settings → Plan**, kept in step with GitHub issues on joshleong/Foundation, one issue per card.

## Under the hood

- **Board schema 6.** The first time a 0.2.0 server starts, it converts existing boards: huddle state moves to its own map. Older servers still open converted boards.
- **The design language has fewer raw colours** (19 → 12, on a ratchet), and no colour transitions that lag the night fade.
- **Sign-ins survive a server restart** mid-way.

## Known issues

- The frame-time check in the browser tests fails on the Windows machine these were built on, before and after this release. It needs a run on a real GPU.
- The installers aren't code-signed yet, so Windows warns when you open them.
