0.3.0 is the first Foundation that updates itself, and a polish release. The plan in Settings now syncs with GitHub in both directions. The board's words got plainer, and a handful of visual faults found in a day-and-night audit of every screen are fixed.

## The plan, synced with GitHub

**Settings → Plan** was a read-only copy of the issues. Now an admin can work the plan from the app:

- **Sync with GitHub.** It reads every issue first, so a title or description someone changed on GitHub wins. An issue closed on GitHub moves its card to Done, so a commit that says `Fixes #67` finishes the card when it lands. Then it sends only what changed in the app: the columns you moved cards to, and the cards you made. It never overwrites what the team wrote.
- **New card.** A bug, a plan, or something that waits on a person, with a milestone, an area and a description. It says *new* until the next sync makes it an issue. A doubled press makes one card.
- **Every card links to its issue.** Press `#67` on a card to open it on GitHub.
- The board says **"synced 3 h ago"**, and the columns line up whatever their descriptions say.

From a terminal, `npm run plan:sync` does the same. And on GitHub, **New issue** offers three forms (Bug, Plan, Needs a person) whose issues join the board on the next sync, in the right column.

## Release notes in the app

**Settings → Releases** shows what every version changed, newest first, starting with this post. The notes are part of the app, so they open offline too, and the version you're running is marked.

## The board says what it means

- A service that answers but has nothing for Foundation to read says **"Up and answering · airformdata.com"**, not a bare "reachable".
- A service that's down says why: **"nothing is running at 127.0.0.1:3001"**, "can't be found from here", "hung up", "its certificate isn't trusted". It used to say "fetch failed".
- Counts agree with their number: **"1 person · 1 board"**, "arranged 1 card".
- "checked 300s ago" reads **"checked 5 min ago"**.
- **The activity log says who did it, as who they are.** A person's own tool calls are logged as theirs, not an agent's (the daily digest counted people as agents). The sections and cards a person adds or removes on the grid are logged too, a burst at a time: "Kai added the section “Supply” and a note “Parts”".

## Also tonight

- **The desktop app updates itself.** A few seconds after it opens, Foundation checks for a newer version and, if there is one, a card says so: **Update and restart**, **Later** or **Skip this version**. Nothing downloads until you press Update. Every installer is signed, and one that doesn't match Foundation's key is refused. After the restart the card says what changed, once. **Settings → Services → Updates** shows your version and checks on demand. This is the first version with it, so 0.3.0 itself is installed by hand once; every version after it arrives on the card.
- **A new icon.** An F laid in masonry: five blue blocks set like stone courses.
- **Two people in one word keep both words.** Notes are now edited in a proper text editor (CodeMirror) bound straight to the shared note, so typing at the same spot at the same moment no longer interleaves letters. Others' carets and selections show in their colour with their name, and ⌘Z still takes back only your own typing.
- **Search reads inside documents.** PDFs, Word, PowerPoint, Excel and OpenDocument files are read after they upload (older files too), so ⌘K and the search pane find them by their words and show the matching line with the match marked.
- **Adding files is easier.** Paste a screenshot or files onto the board and they land under the pointer. Drop a whole folder and it comes in as a group under a note naming it. Every upload goes through one tray at the bottom right: three at a time, with Retry if one fails.
- **Agents ask before they run commands.** An agent can ask to run a command in a machine someone started. The machine card shows the command, and a person presses **Run** or **Decline**. The agent gets the output, and the activity log records who allowed it.
- **Helpers see each other's work.** When an agent calls in helpers, each one sees the lead's plan and what the others have made, so two helpers don't make the same list.
- **The activity log names the agent and whom it worked for**, and also records renames and moves made by hand.
- **The desktop app can use a server on another site.** It signs in for its own session and opens each live connection with a one-time ticket, so a hosted Foundation can work with the desktop app. In a browser on the server's own site, nothing changes.
- **Typing and dragging are lighter.** Typing in a note or dragging a card now redraws only that card and its section, not the whole board's wires, map and grid. A live page squeezed small inside a crowded section shows its still until you zoom in, instead of running.
- **Fixed:**
  - The desktop window could show another app's page when something else held its port.
  - Huddle and agent-command state could be edited by anyone with edit rights. Only the server writes it now.

## Fixed

- **Search's GitHub results are our repos.** A search for "supply" listed strangers' repositories from all of GitHub. It now looks only in the repos this server's GitHub login can see, or in `GITHUB_ORG` when that's set.
- **Search's loading dots no longer spin forever** after you clear the box mid-search.
- **Wires keep to their edge.** Wire landings crowding the far end of a section's edge ran past its corner. They now stay on the edge at both ends and share a short edge evenly.
- **Opening a section, the wires come along.** An expanded section's card grows over half a second, but its wires used to jump to the end at once. They now travel with the card, frame by frame.
- **Inviting a Slack channel to a new huddle is one step.** It used to add the huddle, wait 400 ms for it to reach the server, then send the invite. The server now does both at once.
- **A design pipeline leaves room to turn.** The wire from CAD back round to Simulate had about 14 px to turn into its input, so it hooked tight against the wall. New pipelines start 28 px further in.
- **Pages served by Foundation itself run in a tighter sandbox.** A live page from Foundation's own address could, in principle, lift its own sandbox and act with your session. It now runs without that permission. Pages from other sites are unchanged.
- **Settings → Services lines up**, and on a narrow window each service's details sit under its name instead of in a sliver beside it.
- The sign-in's "Move the cursor — it's the wind" line hides when there's no wind to move (reduced motion, high contrast, no WebGL2).
